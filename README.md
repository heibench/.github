# .github

Org-level configuration for [hardspec](https://github.com/hardspec).

- [`AGENTS.md`](AGENTS.md) — the org-wide contract for humans and AI coding
  agents working in any hardspec repository. Each repo's own `AGENTS.md` wins
  where they conflict; this is the floor.
- [`profile/README.md`](profile/README.md) — what renders on the org landing
  page.
